# Rotina de Fechamento Contábil | RBM Contábil

Aplicação interativa e segura para gestão do fluxo de fechamento contábil mensal das empresas atendidas pelo escritório **RBM Contábil**.

---

## 🚀 Arquivos Principais do Repositório

Para subir no GitHub, os arquivos necessários são:

1. **`Rotina_Fechamento_Contabil.html`** (ou `index.html`)
   - O código completo da aplicação web (interface, tarefas, modal de senha, filtros e controle de empresas).
2. **`README.md`**
   - Esta documentação explicativa com instruções de uso e hospedagem.
3. **`COMO_RECUPERAR_DADOS_RBM.txt`**
   - Guia de orientação e procedimentos de backup para a equipe.

---

## 🔒 Acesso e Segurança

- **Senha de Acesso**: `Rbmcontabil`
- **Controle de Acesso**: Tela modal de bloqueio ao abrir ou recarregar o sistema.
- **Botão Bloquear**: Permite bloquear a tela com 1 clique ao se ausentar da mesa.

---

## 🛠️ Principais Recursos

- **Busca Rápida por Código ou Nome**: Digite o código da empresa para carregar imediatamente a matriz de fechamento.
- **21 Tarefas Contábeis**: Checklist completo de etapas operacionais do escritório.
- **12 Meses (Jan-Dez)**: Status visual claro (`—` Tracinho, 🔴 Pendente, 🟡 Em Andamento, 🟢 Concluído com data).
- **Atribuição de Colaboradores**: Opções para `Viviane`, `Lilian`, `Luziete` ou `[Em branco]`.
- **Enquadramento Tributário**: `Simples Nacional Puro`, `Simples Nacional Híbrido`, `Lucro Presumido`, `Lucro Real`, `MEI`.
- **Tipo de Empresa**: `Abertura`, `Migrada`, `Não informado`.
- **Campo de Observações**: Anotações salva automaticamente por empresa.
- **Backup e Restauração**: Botões para exportar backup em `.json` e importar em 2 segundos em qualquer computador.

---

## 🌐 Como Publicar no GitHub Pages (Link Online Gratuito)

1. Crie um repositório no GitHub (ex: `rotina-fechamento-contabil`).
2. Envie os arquivos para o repositório.
3. Vá em **Settings** > **Pages** no GitHub.
4. Em **Source**, selecione a branch `main` e a pasta `/root`.
5. Clique em **Save**. O GitHub vai gerar um link web online (ex: `https://seu-usuario.github.io/rotina-fechamento-contabil/Rotina_Fechamento_Contabil.html`) para toda a equipe acessar!
